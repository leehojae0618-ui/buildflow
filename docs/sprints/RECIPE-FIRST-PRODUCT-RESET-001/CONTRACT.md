# RECIPE-FIRST-PRODUCT-RESET-001 Contract

## Canonical Recipe Boundary

A BuildFlow Recipe is engine-independent. It contains the goal, trigger,
inputs, steps, outputs, services, connection requirements, candidate engines,
cost, difficulty, automation scope, approval requirements, failure patterns,
alternatives, source/license provenance, and verification status. It is never a
copied third-party workflow export.

## Safety Boundary

```text
Recommendation / preview: local and deterministic.
Connection, credential, OAuth, remote build, Provider call, external execution:
not performed in this Sprint.
```

## Ranking Boundary

Ranking uses explicit policy: goal fit, connection count, cost preference,
verification state, automation coverage, and privacy/external-processing burden.
The result contains user-readable reasons and cautions.
